# Kamaky Products

Aplicación web para la gestión de productos y pedidos de repostería artesanal.

## Descripción
Permite a los clientes de Kamaky Products consultar el catálogo, ver precios
y promociones, gestionar un carrito de compras, realizar pedidos y solicitar
productos personalizados. El administrador gestiona productos, categorías,
promociones, pedidos e información de contacto.
